# 示範步驟

短步驟，不是講稿。

1. 開 `http://127.0.0.1:8787`。未登入時停在 `/login`。底部選單和側欄都不出現。
2. 去註冊。同一頁填電郵、密碼、身高、體重、年齡、生理性別、活動量、目標體重、目標類型、每週訓練天數，並勾選免責。儲存後到 `/home`。登出再登入，檔案仍在。
3. 今日概覽顯示工具算出的 BMR、PAL、TDEE 和課堂目標，以及工具軌跡。
4. 底部選「分析」。用相簿選一張食物相片，或在 HTTPS 上用拍照／開鏡頭（需已設 `XAI_API_KEY`）。多模態 AI 直接回傳菜名與熱量／蛋白質／碳水／脂肪等估算。可改克數後按確認記錄。
5. 回到今日概覽，最近餐點列出剛才那一筆。
6. 「計劃」按一次。畫面列出早餐、午餐、晚餐（預算夠時還有小食）。每項有克數、熱量、營養素和來源編號，並對照課堂目標。訓練句子對照檔案裡的每週天數和公開的 2 天參考，沒有組數次數。
7. 底部選單或側欄直接打開「聊天」。它不是登入後的第一頁。可點提示句填入輸入框，或按「改好這句提示」。送出後氣泡標出 agent，並可展開軌跡。
8. 「更多」只打開「我的檔案」，網址是 `/profile`。
9. 把檔案的儲存時間改成 30 天前再重新整理今日概覽，會看到一次性更新提醒。按「知道了」後這次不再出現。
