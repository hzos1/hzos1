# 示範步驟

短步驟，不是講稿。

1. 開 `http://127.0.0.1:8787`。沒有檔案時停在 `/onboarding`。底部選單不出現。
2. 填身高、體重、年齡、生理性別、活動量、目標體重、目標類型和每週訓練天數。留空不能儲存。儲存後到 `/home`。
3. 今日概覽顯示工具算出的 BMR、PAL、TDEE 和課堂目標，以及工具軌跡。
4. 底部選「分析」。用相簿選一張食物相片，或在 HTTPS 上用拍照／開鏡頭。畫面上先是菜名。改對菜名、填克數，再按確認。卡路里和營養素旁邊有資料列編號。認菜失敗就改手打。
5. 回到今日概覽，最近餐點列出剛才那一筆。
6. 「計劃」按一次。餐單每項有來源編號，總熱量不超過這一餐上限。訓練句子對照檔案裡的每週天數和公開的 2 天參考，沒有組數次數。
7. 「餐廳」先拒絕定位，畫面上說明未查地圖。再輸入地區。有結果就列出 OpenStreetMap 名稱和連結；沒有就顯示查詢失敗。沒有菜單和卡路里。
8. 「更多」分別打開「聊天室」和「我的檔案」。兩頁網址不同。聊天可以再問一句，氣泡標出 agent，並可展開軌跡。
9. 把檔案的儲存時間改成 30 天前再重新整理今日概覽，會看到一次性更新提醒。按「知道了」後這次不再出現。
